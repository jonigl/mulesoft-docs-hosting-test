-   To upload a Mule app JAR file from your system, select Choose file >

-   To choose an example app from Anypoint Exchange:

    A.  Select Choose File > Import file from Exchange.

    B.  In the Get from Exchange page, enter hello in the Search assets
        by name:

        [Get from Exchange page]

    C.  Click Hello World and then click Select.

a.  Select CloudHub 2.0, and then Shared Space for the region from the
    Deployment Target list.

    For the list of regions, see Shared Global Regions. If you have the
    global deployment entitlement, all regions are available. If you
    have region restrictions based on your subscription, only regions
    that are available to your organization appear.

b.  Configure options for deployment:

    -   Specify runtime options.

    -   Change app behavior with properties.

    -   Configure logging for the app.

        1.  Click Deploy Application.
